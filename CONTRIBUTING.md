# Contributing to XRM

Thanks for your interest in contributing to XRM.

XRM is an early-stage open-source project. The goal is to build a practical agency management system for small agencies, freelancers, and service teams.

---

## Ways to Contribute

You can help by:

- Improving documentation
- Reporting bugs
- Suggesting features
- Improving UI/UX
- Refactoring components
- Improving TypeScript types
- Adding tests
- Improving RTL support

---

## Development Setup

Install dependencies:

```bash
npm install

```
Run the development server: 
```
npm run dev

```
Build the project:
```
npm run build

```
Contribution Guidelines

Before opening a pull request:

1- Make sure the project builds successfully.
2- Keep changes focused and small.
3- Avoid large unrelated refactors.
4- Use clear commit messages.
5- Explain what problem your PR solves.

Suggested Commit Format
Examples:
```
docs: improve README
fix: resolve invoice print issue
feat: add project roadmap
refactor: clean project service layer

```
