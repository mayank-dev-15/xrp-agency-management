# Contributing to XRP

Thanks for your interest in contributing to XRM.

XRM is an early-stage open-source project. The goal is to build a practical agency management system for small agencies, freelancers, and service teams.

---

## Ways to Contribute

You can help by:

- Improving documentation
- Reporting bugs
- Suggesting features
- Improving UI/UX
- Refactoring components
- Improving TypeScript types
- Adding tests
- Improving RTL support
