# Roadmap

XRM is currently in early public development. The goal is to turn it into a useful open-source agency operating system for small teams, freelancers, and service businesses.

---

## Phase 1 — Repository Cleanup

- Improve README
- Add license
- Add contribution guide
- Add issue templates
- Add roadmap
- Clean up folder structure
- Improve naming and documentation

---

## Phase 2 — Core Product Stability

- Stabilize CRM module
- Stabilize project management module
- Improve invoice and PDF/print workflow
- Improve team and permission management
- Improve dashboard data consistency
- Fix known UI/UX issues

---

## Phase 3 — Architecture Improvements

- Improve module separation
- Add better state management structure
- Add service layer documentation
- Improve type safety
- Add reusable utilities
- Prepare for backend/database integration

---

## Phase 4 — Open Source Readiness

- Add setup guide
- Add screenshots
- Add demo data
- Add contribution workflow
- Add good first issues
- Add tests for critical flows

---

## Phase 5 — Advanced Features

- Client portal
- Notification center
- Audit logs
- Advanced financial reports
- Custom roles and permissions
- Multi-language support
- Better RTL design system
