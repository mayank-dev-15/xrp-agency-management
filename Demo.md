## About

**xrp-agency-management** is a agency management system.

### Key Features

- CRM (contacts, leads)
- Project management
- Invoice generation
- Team management
- RBAC permissions
- Dashboard analytics

---

## Tech Stack

- React
- TypeScript
- TailwindCSS
- Supabase

---

## Controls & Usage

| Control | Action |
|---------|--------|
| `Dashboard` | Overview |
| `CRM` | Manage contacts |
| `Projects` | Manage projects |
| `Invoices` | Create/send |
| `Team` | Manage members |
| `Settings` | Configure |
