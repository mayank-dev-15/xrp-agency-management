## 📋 Overview

**XRM** is an open-source, AI-assisted agency management platform built for **small agencies**, **freelancers**, and **service-based teams**. It brings together CRM, project management, team collaboration, accounting, invoicing, notifications, role-based access control, and an RTL-first experience — all in one integrated dashboard.

> 🚧 Currently in early public development — actively improving.

---

## 🤔 Why XRM?

Most small agencies juggle multiple disconnected tools — spreadsheets, task managers, chat apps, invoicing software, and manual client tracking. **XRM eliminates the chaos** by consolidating everything into one focused, customizable, open-source system.

| Problem | XRM Solution |
|---------|-------------|
| Scattered tools | One unified dashboard |
| No client history | Built-in CRM |
| Manual invoicing | Automated invoice management |
| Permission confusion | Role-based access control |
| RTL nightmares | Native RTL-first design |

## ✨ Core Features

### 👥 CRM & Client Management
- Manage clients and business contacts
- Link clients directly to projects
- Track project sources and lead origin
- Store client notes, history, and interactions

### 📁 Project Management
- End-to-end project creation and tracking
- Assign team members with specific roles
- Monitor status, budget, expenses, and deadlines
- Full project history and resource timeline

### 👨‍💻 Team Management
- Manage team members and permissions
- Granular role-based access controls
- Track workload and collaboration across projects

### 💰 Accounting & Invoices
- Create, edit, and manage invoices
- Track income, expenses, deductions, and project finances
- Generate print/PDF-ready invoice views

### 🔐 Role-Based Access Control
- **Four-tier access hierarchy:** Admin → Manager → Team → Client
- Permission-aware UI that adapts per role
- Financial visibility rules based on user role

### 🌐 RTL-First UI
- Native right-to-left layout support
- Persian-first interface direction
- Built for agencies operating in RTL languages globally

- [Node.js](https://nodejs.org/) (v18 or later)

```bash

cd xrm

# Install dependencies
npm install
Development Server
bash

Production Build
bash
npm run build
