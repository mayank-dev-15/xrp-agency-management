# xrp-agency-management

[![Live Demo](https://img.shields.io/badge/🚀_Live_Demo-Visit-blue?style=for-the-badge)](https://mayank-dev-15.github.io/xrp-agency-management-demo)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
![Language](https://img.shields.io/badge/Language-TypeScript/React-green)

Open-source AI-assisted agency management system with CRM, projects, invoices, team management, and RBAC.

`crm` `agency` `management` `react` `supabase`

---

## ✨ Features

- CRM — contacts, leads, and client management
- Project management with tasks and milestones
- Invoice generation and tracking
- Team management with role-based access control (RBAC)
- Dashboard with analytics and KPIs
- Responsive design with RTL support
- Real-time updates via Supabase

## 📦 Installation

```bash
git clone https://github.com/mayank-dev-15/xrp-agency-management.git
cd xrp-agency-management
```

```bash
cd xrp-agency-management
npm install
cp .env.example .env.local
# Add your Supabase URL and anon key
npm run dev
```

---

## 💡 Usage

- Access the dashboard at `http://localhost:5173`
- Navigate between CRM, Projects, Invoices, and Team
- Use the admin panel to manage roles and permissions
- All data is stored in Supabase (configure in `.env.local`)
